# IPTV Hero beta builds

Signed private beta builds of IPTV Hero for Android TV. This repository holds only release APKs and `update.json`, which installed betas read to offer updates.

- Each beta stops working 14 days after it is built; install the latest version from the app (Settings > About) or from Releases.
- IPTV Hero is a player only. You need your own IPTV provider account.
- Source code is not published here.
